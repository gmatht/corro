ZORK_WALKTHROUGH — corro 0.7.0 on the zork backend
========================================================================

What this records: the widget tree corro's GUI construction path built
against the in-memory model, and what the grid's draw callback painted
when it was run. Every line is a fact about this backend, read back
out of the model while it was still live.

HOW TO READ
------------------------------------------------------------------------
  [PASS]  the feature is present and reported with evidence
  [MISS]  not present *in the tree as built*. Usually means the
          widget is created on demand (a dialog, a picker), not
          that the feature is missing. See ZORK_MISSING.md for the
          features that are genuinely absent.
  [N/A]   not a widget question (an app-state fact, reported anyway)

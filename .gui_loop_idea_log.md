## 2026-06-26: Session 9 — Fix keyval masking bug in formula entry callback

### Problem diagnosed
The Session 6 unification of formula entry key handling replaced `#[cfg(unix)]`/`#[cfg(windows)]` blocks with a single `formula_entry.on_key_raw()` call. The callback used `keyval & 0xFF` to mask the key value before comparing against `RETURN`/`ESCAPE` constants. ### Changes made
- **`gui_backend.rs:1231`**: Replaced `let masked = keyval & 0xFF;` with `let k = normalize(keyval);`. The `normalize()` function (added in Session 8) correctly strips the extended-key flag on Windows while passing X11 keysyms through on Unix, matching the cross-platform key constants.
